# 原始规则核对及旧模型风险

来源为 `data/raw/决策指南.pdf` 和 `data/raw/市场调研报告.pdf`，以下页码按 PDF 从1开始计数。原件为图像型页面，已渲染阅读；曲线和柱图只用于方向判断，不伪装成精确公式。

| 问题 | 原始依据与结论 | 决策意义 |
|---|---|---|
| 竞争与市场规模 | 指南10页：相似产品竞争且可能内部蚕食；市场总量受增长、平均价格、平均广告、产品种类影响 | 不能逐产品独立预测后直接相加；不能把展望当固定容量 |
| 胜负指标 | 指南11页：股价涉及收益、研发、长期营销、市场地位与增长等，未给精确权重 | 当期净利润最大不等于期末股价最大 |
| 产品设计 | 指南15—16页：增加特性增成本并挤占性能／电池技术空间；技术利用率不能超过100% | 有效规格组合要按平台可行性验证 |
| 固定成本 | 指南16页及参数截图：实体费按地区，每产品管理费按地区，新增或改进产品有生产线成本 | 产品数量与跨市场复用应先于价格微调审查 |
| 预测销量 | 指南18页：供应商按需求调整生产，预测误差会增加单位成本 | 不能套用“预测量就是产量上限”的简单缺货模型；预测仍需认真填写 |
| 广告与渠道 | 指南10、18页：存在延续效应、广告外溢；广告按产品／地区／细分人群，渠道按产品／地区 | 不可把每笔投入当互不影响的一次性变量 |
| 质保和维修 | 指南20页：延保影响需求及未来成本，也减少收费维修；无额外延保仍存在基础质保成本 | 不能只按当期维修利润决定质保 |
| 研发时点 | 指南21页：投资从下一回合通过产品改进发挥技术收益 | 本期研发不能用来证明本期即可上更高规格 |
| 预算 | 指南22页：预算随自己的输入变化；亏损可后续抵扣税 | 预算不构成对手竞争下的需求预测 |

## 调研揭示的市场差异

- 调研2—3页：性能对高端群体更重要，电池对企业群体更重要；均是相对竞争产品的关系。
- 调研3页：欧洲四类群体图中运动外观偏好最高。4页：亚洲普通消费者、企业及高端企业偏经典；高端消费者前卫略高于经典；运动最低。**旧配置把亚洲运动设为高偏好，不能沿用。**
- 调研4页：延保需求效果因群体不同；图中普通消费者和企业群体较明显。不能据此直接求最优延保月数。
- 调研5页：价格敏感度存在差异，企业和普通消费者较敏感，高端企业也不是完全不看价格。图中是需求影响指数，不是销量。
- 调研6页：消费者重视相机、存储等，企业群体尤其重视安全；各地区、高端与普通群体有差异。调查重要性分数不是可直接塞入效用函数的系数。
- 调研7—8页：广告有延续效应；两地区针对性广告的预期作用被说明为相同。不能断言亚洲广告效果天然只有欧洲四分之一。图示的递减与AIDA例子不等于已验证模拟器公式。
- 调研8—9页：企业群体明显偏专业渠道，两地区消费者的渠道结构有差别。不能把一套渠道比例无差别用于所有地区和群体。

## 旧代码审查发现

旧资料现均在 `archive/legacy-model-2026-10-17/`。阅读时注意：

1. 旧数值转换对“x”等特性标记可能转为0，产品特征信息丢失，相关分析应重做后再用。
2. 以相对价格、广告、渠道拟合所得系数，不能称为因果弹性。产品特性、产品数量、共同市场变化及内生决策会干扰估计。
3. 独立 sigmoid 不能自动保证所有竞争产品份额加总合理，也未完整处理内部蚕食。
4. 把销量预测作为硬生产／缺货约束，与指南关于供应商调整生产及预测误差成本的说明冲突。
5. 任意组合利润和份额的目标函数，不是官方股价公式。用其搜索出的“最优”只是在该假设下最优。

今晚不以重写需求模型为前提。先使用经核对的成本结构、可行性约束及竞争情景筛选，承认实际需求仍有区间。
