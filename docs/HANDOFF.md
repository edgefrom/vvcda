## 新电脑启动

```text
git clone https://github.com/edgefrom/vvcda.git
cd vvcda
python -m pip install -r requirements.txt
python -X utf8 analysis/verify_workspace.py
```

Python3.11+，使用系统环境，不创建venv。只阅读无需安装。让AI打开克隆后的根目录，不需要原电脑的C盘路径。现有图表已经入库；重新生成中文图表需要中文字体。

## 分工和交接

负责人合并证据并确认最终方案，其他成员按明确任务独立复核，例如需求／竞争、股价候选关系、数据核验。每份返回成果注明起始Git提交、数据阶段／回合／赛区、方法、假设、验证、残差和建议，用独立文件或分支返回。重要人类决定必须写入仓库；共享账号不代表GPT自动继承全部聊天背景。

最值得补的资料：正式第1轮最终生效小组清单、第2轮最新前景和参数。获取后放manual；截图需标明回合和小组，不要只截成员个人草稿。
