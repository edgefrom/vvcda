## 1. 最重要的两个全局结论

1. **练习回合不计入成绩**，但**正式回合 1 的初始决策从练习回合 1 导入**。
   因此：练习回合可大胆做实验（无成绩风险），但练习回合 1 结束时应留一套合理决策作为正式开局。
2. **对手决策完全可见**：结果导出的 Excel 包含全部 12 家公司的定价、广告费、渠道投资、研发投资、市场调研投入、销量、市场份额。→ 这是**显式博弈**，对手上回合动作可直接观测，而非黑箱。

## 2. 决策空间（真实结构，多产品）

### 2.1 产品（4. 产品 / 4.1 产品组合）
- **6 个产品位**；产品数量是成功组合的最重要因素之一，建议随市场发展逐步增加。
- 每个产品可独立决定投放市场：欧洲 / 亚洲 / 两者 / 都不投（不选=不可购买）。
- 产品属性：
  - **设计/款式**（不影响成本，影响差异化）
  - **附加特征**：每产品最多 5 个（3000 万像素镜头、额外存储、高级屏幕、高精度导航模块、指纹加密）；加特征增加成本，且**降低最大轻薄度/电池寿命**。
  - **轻薄度 & 电池寿命**：所有细分都喜欢更高；水平越高单位成本越高。技术指数初始 100，**研发投资可推出 >100 的产品**。
  - **技术使用率**：每项特性占用待机时间/复杂度；接近 100% 时加新特性需删减其他属性。系统禁止导致产品无法实现的决策。
- **生产线成本**：仅在调整产品属性/推新品时产生；与上回合保持相同属性可避免 → 长期规划产品组合能省钱。

### 2.2 市场（5. 市场）
- **定价**：同一产品可在两市场不同价；价格敏感度因市场/细分而异。
- **销售预测**：是**预估值而非实际决策**，但影响预算，且是向生产公司下单的基础；**预测偏差越大，紧急调整的单位成本增幅越大**。
- **广告**：按「市场 × 产品 × 细分」设置预算；对某细分的广告对其他细分有溢出；广告有长期影响。
- **渠道投资**：按「产品 × 渠道」分配（3 渠道）；有长期影响。

### 2.3 客户服务（6. 客户服务）
- **额外质保**：范围（如中度）；对需求有积极影响，但增加当前+未来成本；质保越长越挤压维修收入。
- **维修质量投资**：拉动维修需求，对产品需求有微小影响。
- **维修定价**：维修价格/小时；由生产方成本 + 边际收益决定。

### 2.4 研发（7. 研发）
- 按产品属性分别投资（智能手机案例 = **轻薄度、电池寿命**）。
- 技术指数 = f(本回合研发、上回合技术、市场平均技术水平)。
- 研发极具战略意义、难精确计算；随意研发易损失大量资金；应考虑「卖出多少产品才能收回研发资金」。

### 2.5 其他决策
- **付款条款**：适用于所有客户群/市场的回款期限；较长回款期对需求有很小积极影响，但增加应收账款。
- **市场调研**：分市场投入（结果文件显示 600 / 800 两档）。
- **自动贷款**：流动性不足时自动产生贷款。

## 3. 需求机制（2.2）

- **总体市场规模**取决于：市场增长率、市场均价水平、广告平均水平、产品细分品类数量；**单个公司影响市场总需求的能力很小**。
- **公司市场份额**取决于：**相对价格、相对广告、相对渠道投资、产品属性、客户服务**。
  → 这就是吸引力模型的官方输入清单，与我们的 logit 基线完全对齐。
- **蚕食**：高度相似的产品互相蚕食份额（客户基础重叠）。
- 广告和渠道投资对需求有**长期影响**，随时间减弱。

## 4. 获胜标准（2.3）—— 股价函数构成

股价主要受以下影响，且**所有回合都会影响最终股价**：
1. **收益水平**（盈利）
2. **研发活动**（合理研发预示未来增长）
3. **管理团队能力**（长期绩效评估）
4. 细分市场中的强势定位 / 市场快速增长 → 轻微积极影响
5. **营销传播的适当长期投入**（广告提高知名度、渠道投资提高覆盖率）→ 投资者青睐
6. 高增长市场往往伴随较高风险（不确定因素）

> 启示：股价 ≠ 单纯利润最大化。研发、营销长期投入、细分定位都有权重。
> 这正好印证了机制说明书 P6「相对排名目标」的必要性，以及代理目标应包含研发与营销长期项。

## 5. 财务结构（8. 结果预估）

### 损益表（8.1）
总收入 = 产品销售收入 + 担保收入；
可变成本（按产品）；
毛利润 = 总收入 − 可变成本；
固定成本 = 管理层成本 + 广告费用 + 生产/技术成本 + 市场研究费用 + 折旧 + 坏账等；
营业利润；利息收支；税前利润；所得税；**亏损结转**（前几回合亏损可抵未来税）。

### 资产负债表（8.2）
资产：应收账款、库存/存货价值、资产总计；
权益：股本、留存收益；
负债：应付账款等。
- 决策充电：**尽量保持资产负债表紧凑**（同样利润下更轻的资产负债表 = 更高效利用资产）。

## 7. 对建模的直接含义

1. 需求模型输入（官方给定）：相对价格、相对广告、相对渠道投资、产品属性（轻薄度/电池寿命/特性/款式）、客户服务。
2. 存在跨期状态：技术指数、广告/渠道的长期效应、品牌知名度、亏损结转、库存。
3. 对手决策可观测 → 可做显式对手建模与相对量（相对价格/广告/渠道）计算。
4. 决策空间是「产品组合 + 定价 + 营销 + 研发 + 服务」的**分层组合优化**，非单一向量。
