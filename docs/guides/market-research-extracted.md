## 2. 市场结构（已核实）

- **两个区域**：欧洲（EU）、亚洲（ASIA）。
- **每区域 4 个细分**：
  1. 普通消费者（consumer，低端家庭用户）
  2. 高端消费者（premium，高端家庭用户）
  3. 企业用户（business，低端企业用户）
  4. 高端企业用户（premium_business，高端企业用户）
- **3 个销售渠道**：品牌专卖店、家电卖场、百货商场。
- **3 种款式**：经典、前卫、运动。
- **5 个产品特性**：3000 万像素镜头、额外存储、高级屏幕、高精度导航模块、指纹加密。

## 3. 市场调研报告要点（9 页）

### 3.1 性能（1.1）
- X 轴 = 性能指数（-50% ~ +50%），Y 轴 = 净推荐值 %。
- 性能越高需求越大；**高端消费者与高端企业用户**斜率更陡（更敏感）。
- 欧洲与亚洲斜率不同。

### 3.2 电池寿命（1.2）
- 欧洲与亚洲**基本相似**，可共用一张图。
- **企业用户与高端企业用户**斜率最陡（最敏感）；消费者细分较平。
- 结论：电池寿命对 B 端（企业）细分价值最高。

### 3.3 款式（1.3）
- 欧洲：**运动型**在各细分得分最高；经典最低；前卫在高端消费者中较高。
- 亚洲：结构相似（低端偏经典、高端偏前卫/运动，待校准）。

### 3.4 保修期（1.4）
- X 轴 = 保修月数（6/12/18/24/36/60），市场平均约 **12 个月**。
- 长于平均的保修期促进需求；6 个月时多数细分为负。

### 3.5 价格（1.5）
- Y 轴 = 需求指数（只反映弹性，非实际量）。
- 各细分价格弹性不同。结合案例背景：
  - **亚洲家庭用户价格最敏感**（比欧洲家庭用户更敏感）。
  - **高端企业用户（尤其亚洲）价格影响很小**。

### 3.6 特征（1.6）
- 5 个特性用李克特量表（不重要→非常重要，0~3）打分，欧洲/亚洲分别展示。
- **精确分档待人工读图**（`feature_importance` 暂空，见 `config/market_research.yaml`）。

### 3.7 广告（2.1 长期效应 / 2.2 效果 / 2.3 渠道偏好）
- **长期效应**：一次性投入逐期衰减；持续投入累积增长（广告有跨期结转）。
- **AIDA 漏斗**：100 注意 → 20 兴趣 → 10 欲望 → 5 购买（认知→购买转化约 5%）。
- **定向广告 +10% 预算的细分拉动**（两市场相同）：
  - 普通消费者 1.25%，高端消费者 1.4%，企业用户 0.6%，高端企业用户 0.8%。
  - 结论：**广告对家庭用户作用大于企业用户**。
- **渠道偏好**（% 偏好该渠道的客户，近似）：
  | 细分 | 品牌专卖店 | 家电卖场 | 百货商场 |
  |---|---|---|---|
  | 普通消费者 | ~15 | ~50 | ~35 |
  | 高端消费者 | ~30 | ~25 | ~45 |
  | 企业用户 | ~70 | ~20 | ~10 |
  | 高端企业用户 | ~80 | ~12 | ~8 |
  - 结论：**企业细分高度偏爱品牌专卖店**，消费者细分更分散。

## 4. 案例背景要点

- 团队控制**市场营销侧**，兄弟公司负责生产；需支付生产成本。
- 市场增长火爆，多家公司同起点。
- 研发有长期影响：核心竞争力 = **轻薄度 + 电池寿命**，取决于前几年研发累积。
- 轻薄度：**亚洲要求强于欧洲**；高端用户 > 低端用户。
- 电池寿命：家庭用户不那么重要（与企业用户对比）。
- 渠道投资在各渠道效果相差不多，但**不同细分渠道份额不同**（即渠道组合=细分选择）。
- 款式差异化：若对手只主打一种好卖款式，差异化款式会卖得更好。

## 5. 结果导出格式（results-ir00.xls，已解析）

文件为「宽表」，**每列一家公司（A~L，共 12 家），行 = 指标**。关键区块：

- **产品与定价**：每公司 1~5 个产品（P1~P6），每个产品有欧洲/亚洲定价（€）。
- **销售量（千个）**：按 4 细分（普通/高端消费者、企业/高端企业用户）× 市场。
- **渠道销售量**：品牌专卖店 / 家电卖场 / 百货商场。
- **市场份额（%）**：按细分。
- **决策变量（可反推）**：广告费、渠道投资、研发投资、市场调研（600/1200）、生产线成本（6600/8800/11000）。
- **产品认知、购买意愿和销售情况**：认知度与购买意愿漏斗。
- **财务**：产品销售额、销售合计、生产线成本、广告费、渠道投资、研发投资、市场调研、现金及等价物、资产总计、利润、总负债、销售回报率（%）、**销售预测误差（%）**。

## 6. 反推的决策变量清单

| 决策 | 说明 | 单位/档位 |
|---|---|---|
| 产品数量 | 1~5 个（P1~P6） | 整数 |
| 定价 | 每产品 × 每市场 | € |
| 产品特性 | 5 个特性（镜头/存储/屏幕/导航/指纹） | 配置组合 |
| 款式 | 经典/前卫/运动 × 产品 | 分类 |
| 广告费 | 分市场 | 千元 |
| 渠道投资 | 分市场 | 千元 |
| 研发投资 | 全局 | 千元 |
| 市场调研 | 全局 | 600 / 1200 |
| 生产线成本 | 全局 | 6600 / 8800 / 11000 |
| 销售预测 | 分市场（驱动生产，预测误差有成本） | 千件 |

> ⚠️ 关键发现：真实决策是**多产品**结构（每个产品有独立价格/特性/款式），
> 当前 `DecisionVector` 是扁平结构，需扩展以支持「产品 × 市场 × 特性」。
> 精确表单结构与范围以 `决策指南.pdf`（36 页）为准。
