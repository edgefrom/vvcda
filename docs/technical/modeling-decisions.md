# 建模决策记录（方法论）

> 本文档记录团队讨论后确定的建模决策、理由与优先级，避免未来重复纠结同一问题。
> 更新日期：2026-10-13。每一项决策都写明「结论 + 理由 + 替代方案」。

## 已确认的事实（作为决策前提）

1. **一个队伍 = 一家公司**，与同赛区约 9 家对手竞争（真实数量以登录后赛区名单为准）。
   - 注意：早期样例 `results-ir00.xls`（12 家公司）已移除，练习回合真实结果见 `data/raw/results/`。
2. **预测基础 = 过往公开结果导出**（含所有公司的定价/广告/渠道/研发/份额/股价）。
   - 永远看不到对手「本回合正在填写的决策」——结算后才公开。
3. **对手决策可见 → 显式博弈**：结果导出包含全部公司的决策。
4. **份额模型已通过「相对量」隐式考虑对手整体**（相对价格/广告/渠道的分母 = 市场均值）。

## 已定决策

### D1. 不做「假设对手完全理性」的纳什预判（作为主策略）
- **结论**：放弃"假设完全理性 → 解均衡 → 预判"作为**主策略**的路线。
- **理由**：① 对手是学生队伍，多数是"跟风降价/报复性广告"的简单规则，不是理性优化者；② 收益函数是黑箱（连我们都还没估准），完全理性所需的"共同知识"不成立。
- **替代**：情景对冲（见 D3）。
- **补充（2026-10-13）**：为防御「对手也用量化模型」的情形，新增**可插拔纳什预判** `opponent/nash.py`（`nash_price_equilibrium`），作为"最坏情景"之一输入优化器；**默认不启用**，非主策略。

### D2. 不做反应函数估计（已砍掉）
- **结论**：不估计"每家对手对我方动作的反应函数"。
- **理由**：轮次太少（练习 2 + 正式 8 ≈ 8~9 个对手轨迹点），估计稳定反应函数必然过拟合；对手自身也在学习、会变，"稳定风格"不存在。

### D3. 对手建模降级为「粗略分类 + 情景对冲」，且后置
- **结论**：对手建模只保留最轻量一档——粗略分类（激进/跟风/稳健）+ 保守情景压力测试（"对手集体降价 10% 我还扛得住吗"），甚至可继续后置。
- **理由**：在需求参数估出来之前，预判对手没有意义（算不出对方动作的实际伤害）。
- **现状**：`opponent/` 只保留分类与档案骨架，不扩展。

### D4. 需求模型用「logit 线性」，这是平台机制的正确形式
- **结论**：`份额 = sigmoid(β₀ + Σ βₖ·xₖ)`，即 logit(份额) 对特征线性（logistic 回归）。
- **理由**：平台是 attraction model（吸引力加权分配份额），与 logit 同族；决策指南 §2.2.2 明示份额取决于相对价格/相对广告/相对渠道/产品属性/客户服务。
- **已处理的部分非线性**：广告/研发等饱和效应用 `log` 变换（`transforms={"...": "log"}`）。

### D5. 非线性风险用「先验变换 + 验证」控制，升级路径留而不上
- **结论**：不主动上复杂非线性模型；用市场调研报告的先验曲线定变换；用留出法/交叉验证把关。
- **理由**：样本仅约 160 个观测（10 回合 × 8 细分 × 2 市场），少样本下"结构正确 + 简单"胜过"复杂 + 灵活"，复杂非线性更易过拟合噪音。
- **升级路径（留待数据充足）**：多项式 logit / 贝叶斯非线性（高斯过程）。触发条件 = 验证显示线性 logit 预测误差明显偏大。

### D6. 优先级排序
1. **需求参数估计**（最高）：先知道自己"降价能带来多少份额"。
2. **财务 / 约束仿真**：损益表、亏损结转、自动贷款、销售预测→缺货成本。
3. **对手情景对冲**（轻量，可后置）。
4. **分层优化**（产品组合 → 定价/营销 → 研发）。
