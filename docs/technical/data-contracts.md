# 当前审计数据约定

旧schemas.py只在archive中保留，不是本阶段输出的权威结构。

- 当前解析器接受首表290行结果，核对中文标签；每队产品6槽、财务1列，分别定位。其他布局停止，不猜偏移。
- 财务千欧元、数量千台、单价／成本／股价欧元；缺失None，特性x为布尔，不补0。
- results_reader输出cohort、roster、phase、source、records、markets、reconciliation_errors；records含team、finance、products、services、源列及排名。
- cohort是完整排序名单哈希，只是匹配标识；结合阶段和回合才定位观测，不替代官方赛区ID。
- data/intake记录原路径、规范／归档路径、哈希、语义哈希、分类及重复关联。历史反斜杠路径需兼容转换。
- diagnosis.json包含建议／实际对照、会计桥接、市场份额算术拆分、同行统计、异常、未确认输入与源哈希；底稿保留精确值，报告展示四舍五入值。
- 当前明确标记的外赛区产品成本／营销差异不用于参数估计；内部平衡财务可用于有限描述统计。本队赛区必须全部勾稽通过。
- 建议quantity不是实际提交；历史预测不可追改。预测模型另建版本、样本划分和验证记录。
