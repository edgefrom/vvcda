# 历史与来源归档

- `legacy-model-2026-10-17`：旧模型隔离区，可靠性警告见下文。
- `manual-imports`：人工下载原始字节及原目录，按data/intake清单追溯；不是旧模型的推断。
- `decision-snapshots`：事前建议及假设的冻结快照，用于复盘，不能当下一轮输入。

三类归档不要混用；原件作为来源也仍需检查阶段、重复和数据异常。

**下面的旧模型材料不完全可靠，不能视为比赛规则、当前状态或已验证最优策略。**

legacy-model-2026-10-17 保留旧代码、配置、测试、脚本和文档。测试通过只能说明部分实现符合自身假设，不能证明假设符合 CESIM。即使旧文档使用“真实”“验证”“最优”等字样，也需重新核对来源。

原文件不改写，便于追溯；其中 README 和 original-AGENTS.md 仅说明历史项目。当前入口是根目录 README.md 和 AGENTS.md。
